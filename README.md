# 鲸鲸研究院 · WhaleGirl Lab

这里是鲸鲸的开发协作仓库，用于功能试验、问题复现和代码评审。

| 入口 | 用途 |
| --- | --- |
| [鲸鲸主仓库](https://github.com/Banan1cee/whale_girl) | 项目主线、正式发布和用户反馈 |
| [下载安装包](https://github.com/Banan1cee/whale_girl/releases/latest) | 稳定版 Windows 安装包 |
| [使用指南](https://github.com/Banan1cee/whale_girl/blob/main/docs/README.zh-CN.md) | 安装、配置与功能介绍 |

## 开发协作

1. 以[主仓库的 `main`](https://github.com/Banan1cee/whale_girl/tree/main) 为基线，先看[已有 PR](https://github.com/Banan1cee/whale_girl/pulls)，再开工作分支。
2. 在 Lab 提 PR，附复现步骤和验证结果。开发与测试约定见[贡献指南](CONTRIBUTING.md)。
3. 需要随正式版本发布的改动，评审后向主仓库提 PR。正式版本由主仓库发布。
